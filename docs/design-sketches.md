# Tillämpning av sidskisser

Källa: bifogade `stitch_f_rena (2).zip`. Skisserna används för layout och
formspråk för befintliga funktioner; exempeldata och extra funktioner överförs
inte till produktionsvyerna. Originalarkivet är referensmaterial, inte en
implementation eller en källa till verksamhetsregler.

Skissen för Lägg till uppgift (Inklistrad text.txt) används för aktivitetens
verkliga namn, tider och plats, kort för uppgiftstyp, tid/bemanning och
instruktioner samt gemensamma 48 px-reglage för antal platser. Självbokning,
manuell tilldelning och befintligt rättviseförslag behåller separata flöden
efter att uppgiften granskats och sparats. Fasta F2016-mallar, automatisk
före-/eftermatchsynkning, PDF-guide och trygghetsnotis införs inte; de saknar
befintligt verksamhetsstöd och pass måste rymmas inom aktivitetens tider.

| Skiss | Tillämpning i Förena |
| --- | --- |
| Närvarorapportering mobil | Antal, tydlig snabbåtgärd, sökning, filter och stora närvarorader |
| Ny aktivitet | Kort för detaljer, tid/samling och kallelse; tydliga val och granskning |
| Lägg till sekretariatsuppgift | Namn, tid, kapacitet och instruktioner med samma uppgiftskommandon |
| Skapa/redigera arbetspass | Grupperad tid/bemanning och instruktioner; befintlig seriegenerering |
| Kombinerat schema | Tidsatta uppgifter och deadline-uppgifter i samma kortlista |
| Rättvis fördelning | Avgränsat ledarverktyg med befintliga statistikregler och granskning |
| Boka arbetspass | Kapacitetsöversikt, tidkort, lediga platser och markering av eget pass |
| Hantera/byt arbetspass | Hopfällbart hanteringsavsnitt med befintligt byte/ersättarflöde |
| Flerlagsöversikt | Aktivitetskort med klubb/lag, direkta svar per person och samlad agenda |

LOK-stöd/signering, provspelare, tränarloggbok, passmallar, automatiska
före-/eftermatchstider, nya rättviseregler, meddelanden mellan föräldrar,
kalenderexport, byte mellan aktiviteter och bottennavigation ingår inte.
Datum och tider väljs med appens befintliga kontroller; skissens egna kalender
och plus/minus-reglage kopieras inte.

Gemensamt sidskal, behörigheter och bekräftelseflöden återanvänds.
Sidorna laddar inga skript från skissfilerna.

Skissen i `stitch_f_rena (3).zip` preciserar lagöversikten: två paneler på
desktop och en separat svarrad per kallad person. Den gemensamma
`PersonalOverview` visar samma kort i lagets och familjens översikt.
