6. Råd för Idrottsledare & Föräldrar

check_circle Gör så här (DO)
  • done Placera huvudknappar längst ner: Låt föräldern bekräfta med en hand i farten på parkeringen.
  • done Stora touchytor: Minst 44x44px (helst 48px) så man kan pricka rätt även med kalla händer eller vantar.
  • done Direkt visuell bekräftelse: Ändra bakgrundsfärg omedelbart vid klick på närvaroknappar.
cancel Undvik detta (DON'T)
  • close Inga dolda flerstegsmenyer: Göm inte kioskbyten bakom tre punkter när en snabbknapp kan göra jobbet direkt.
  • close Undvik minimala kryssrutor: Använd dedikerade klickkort eller tydliga runda närvaroregler.
  • close Lås inte skärmen med popups: Modalrutor i regn skapar frustration. Använd mjuka inline-aviseringar.
